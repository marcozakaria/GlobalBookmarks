Global Bookmarks (Unity Editor Tool)
Global Bookmarks helps you save and instantly navigate to frequently used assets and scenes in your Unity project.

Features:
•	Add bookmark from current selection
•	Supports multiple types: Scene, Prefab, Material, Texture, Folder, Video, Audio, Script, ScriptableObject, Other
•	Fast search by name or type
•	Sorting options (name ascending/descending, type then name)
•	Scrollable bookmark panel
•	Duplicate prevention (same GlobalObjectId cannot be added twice)
•	Quick open button for scene bookmarks
•	Per-item icons and tooltips with path/type details

How to Use:
1.	Open Tools > Bookmarks
2.	Select any supported object in Project/Hierarchy
3.	Click + to add bookmark
4.	Click bookmark name to select it
5.	Use Open for scene bookmarks
6.	Use search and sort controls to organize navigation

Notes:
•	Bookmarks are stored in a ScriptableObject asset and persist in the project.
•	Missing or moved assets may show unavailable path in tooltip.
